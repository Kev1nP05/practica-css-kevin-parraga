# Senderos del Ecuador

Sitio educativo creado para el Laboratorio 3 de Fundamentos de Sistemas Web.
Presenta consejos para caminar, una galería de paisajes y ejemplos de recorridos.

## Cómo abrirlo

Descarga el proyecto y abre `index.html` en un navegador.

## Tecnologías

- HTML5 y CSS externo
- Git y GitHub

## Funcionalidades

- Menú con enlaces a las secciones del sitio.
- Galería de seis fotos, dos de ellas ampliables.
- Tabla de recorridos y formulario con validación básica.
- Sección de equipamiento desarrollada como reto.

## Archivos

- `index.html` — contenido del sitio.
- `css/estilos.css` — estilos de la página.
- `imagenes/` — portada, galería y fotos del reto.
